# Omni Translate

Omni Translate 是一个面向 Windows 首发的实时音频翻译桌面项目，目标覆盖视频字幕翻译、游戏双向语音翻译、虚拟麦克风自动安装和可配置大模型 Provider 接入。

当前仓库已包含：

- desktop 前端骨架
- 项目文档基线
- workspace 配置
- 贡献指南与发布自动化基线

## 快速开始

1. 安装 Node.js 20 或更高版本。
2. 在仓库根目录运行 `npm install`。
3. 运行 `npm run dev:desktop` 启动前端骨架。
4. 运行 `npm run build:desktop` 验证构建。
5. 运行 `npm run release:verify` 做发布前校验。
