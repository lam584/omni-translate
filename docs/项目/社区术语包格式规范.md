# Omni Translate 社区术语包格式规范

## 1. 目标

1. 让术语包具备稳定的导入导出能力。
2. 让用户自定义术语包和社区共享术语包使用同一套 manifest 结构。
3. 让未来的词典市场、模板仓库或本地导入器都能复用当前格式。

## 2. 当前版本

1. manifestVersion：`1.0`
2. 当前导出格式：`json`
3. 当前读取策略：向后兼容 `1.0`

## 3. 顶层字段

1. manifestVersion：格式版本号，当前固定为 `1.0`。
2. packageId：术语包唯一标识。
3. version：术语包自身版本，推荐使用 semver。
4. kind：当前允许 `user`、`community`、`game-dictionary`。
5. scenario：当前允许 `watch`、`game`、`voice-room`。
6. label：展示名称。
7. description：简要说明。
8. source：来源标识，当前允许 `local-export`、`community-curated`、`community-contributed`、`official-template`。
9. author：作者或维护者标识。
10. updatedAt：最近更新时间，推荐使用 `YYYY-MM-DD`。
11. exportFormat：当前固定为 `json`。
12. conflictPolicy：冲突策略，当前允许 `merge`、`replace`、`keep-user-entry`。
13. localePair：源语言和目标语言。
14. compatibility：兼容性声明。
15. entries：词条数组。

## 4. compatibility 字段

1. minReaderVersion：最小读取器版本，当前固定为 `1.0`。
2. backwardsCompatible：当前版本是否可被旧读取器兼容。
3. upgradeNotes：升级说明数组，用于解释字段变更和导入约束。

## 5. entries 字段

1. id：词条唯一标识。
2. sourceTerm：原始词条。
3. targetTerm：目标词条。
4. aliases：可选别名数组。
5. note：可选补充说明。
6. tags：可选标签数组，建议用于游戏、场景或地图维度分类。

## 6. 冲突规则

1. `merge`：新词条并入现有术语包，同 id 或同 sourceTerm 时以导入器策略合并。
2. `replace`：导入包替换目标包的全部词条。
3. `keep-user-entry`：社区包或官方词典不得覆盖用户显式词条，只能补充不存在的默认项。

## 7. 导入导出约束

1. 导出器必须始终输出完整 manifest，不允许只导出 entries。
2. 导入器必须先校验 manifestVersion，再校验 kind、scenario 和 conflictPolicy。
3. 社区包导入时必须保留 source、author 和 version 字段，便于溯源。
4. 游戏词典建议按 title 或房间场景拆包，不把地图、角色和模式硬编码到 manifest 顶层。
5. 当前版本不包含在线签名、市场评分和云同步字段。

## 8. 示例

```json
{
  "manifestVersion": "1.0",
  "packageId": "community-anime-cn-v1",
  "version": "1.3.0",
  "kind": "community",
  "scenario": "watch",
  "label": "社区动画同传术语包",
  "description": "由社区维护的动画和字幕组相关术语。",
  "source": "community-curated",
  "author": "community-maintainers",
  "updatedAt": "2026-05-10",
  "exportFormat": "json",
  "conflictPolicy": "keep-user-entry",
  "localePair": {
    "source": "ja-JP",
    "target": "zh-CN"
  },
  "compatibility": {
    "minReaderVersion": "1.0",
    "backwardsCompatible": true,
    "upgradeNotes": [
      "社区包不能覆盖用户显式术语，只能补充默认词条。"
    ]
  },
  "entries": [
    {
      "id": "term-seiyuu",
      "sourceTerm": "seiyuu",
      "targetTerm": "声优",
      "tags": ["anime"]
    }
  ]
}
```
